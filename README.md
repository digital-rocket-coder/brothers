# ГОНГ — лендинг приложения для бокс-клубов

Одностраничный лендинг white-label мобильного приложения для боксёрских клубов
(рабочее название «ГОНГ»). Статический сайт: один `index.html`, без сборки.

Кейс/демо — Brothers Boxing Club. Внутри живой боксёрский раунд-таймер,
тёмная и светлая темы, адаптив под телефон.

## Структура
- `index.html` — вся страница (разметка, стили и скрипт инлайн)
- `vercel.json` — статическая отдача, чистые URL, базовые заголовки безопасности

## Локальный просмотр
Открыть `index.html` в браузере, либо:
```bash
npx serve .
```

## Деплой на Vercel
Статический сайт без фреймворка — Vercel определит это сам.
```bash
vercel          # превью
vercel --prod   # прод
```
Либо через дашборд Vercel: **Add New → Project → Import** этот репозиторий.

## Важно
- Форма заявки сейчас демонстрационная (не отправляет данные). Перед продом
  подключите обработчик: Vercel Form / serverless-функцию / внешний сервис.
- Онлайн-оплата, синхронизация с носимыми устройствами и админ-панель
  помечены как «Скоро» — не обещать как готовое.
- Отзыв владельца и цифры в блоке «Кейс» — заглушки, заменить реальными.
- Контакты в футере и тарифы — заглушки `[...]`.
